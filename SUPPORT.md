# Support

Floci UI is an open source desktop app for local Floci emulator workflows.

## Where to Ask

- Use GitHub issues for reproducible bugs and scoped feature requests.
- Use GitHub discussions only if the repository maintainers enable and monitor
  discussions.
- Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

## Bug Reports

Include:

- Operating system and version.
- Floci UI version, branch, or commit.
- Rust version and whether `rust-toolchain.toml` was used.
- Floci version or container image.
- Endpoint URL shape, such as `http://localhost:4566` without secrets.
- Steps to reproduce.
- Expected behavior and actual behavior.
- Relevant logs or screenshots.

Do not include real credentials, tokens, private keys, or production AWS data.

## Feature Requests

Include:

- The local emulator workflow you are trying to complete.
- The AWS-compatible service involved.
- Current workaround, if any.
- Why the change belongs in Floci UI rather than Floci itself.

## Out of Scope

- Production AWS account troubleshooting.
- General AWS support.
- Support for remote non-local endpoints.
- Guaranteed response times.
- Private consulting or custom desktop builds.
